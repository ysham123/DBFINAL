# Verifying your installation

Start the backend and frontend using [the README](README.md#local-setup). Check `/api/health` for database connectivity.

1. Register a client and submit a service request, including a photo.
2. Sign in as Anna and send a quote from Requests.
3. Sign in as the client and accept or counter the quote.
4. As Anna, complete the resulting order and generate a bill.
5. As the client, record an external payment or dispute the bill.
6. As Anna, revise a disputed bill and check the reports.

These are manual verification steps, not a claim that a particular installation is running or has passed testing.
